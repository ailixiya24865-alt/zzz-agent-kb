# 绝区零 Agent 知识库（ZZZ Agent KB）

> 覆盖《绝区零》（Zenless Zone Zero）2024-07-04 公测至 **3.3「重返天空的旅程」**（2026-10-21）的知识库。
> 本库为「可被 AI Agent 直接调用」而设计：既有结构化知识，也有检索路由、回答规则与更新流程。

## 1. 这是什么

这不是一份剧情读后感，而是一套**面向问答与分析的知识底座**：

- **知识层**：世界观、战斗、养成、玩法、版本、代理人、剧情、抽卡、配队、术语、FAQ。
- **检索层**：`00-索引.md` 把「用户问什么」映射到「该读哪个文件」。
- **代理层**：`AGENT.md` 定义 Agent 的身份、边界、回答规范、防幻觉策略。
- **接口层**：`SKILL.md` 可直接作为 Skill 入口；`manifest.json` 供程序读取元数据。
- **数据层**：`data/agents.csv`、`data/versions.csv` 可直接被脚本/表格工具消费。

## 2. 快速开始

**人类读者**：先看 `00-索引.md`，再按兴趣跳转。

**AI Agent**：
1. 读取 `AGENT.md`，加载身份与规则；
2. 按 `00-索引.md` 的路由表定位文件；
3. 只引用文件中的事实；文件未覆盖的内容明确说「知识库未收录」；
4. 涉及版本差异时，先确认用户所在版本。

**接入 DSH / 其他支持 Skill 的运行时**：把 `SKILL.md` 作为技能入口，知识库目录作为资源目录。

## 4. 数据口径

- **版本口径**：以国服（中国大陆）版本号与日期为准；国际服通常同一天或相差数小时。
- **强度口径**：默认参考 Prydwen 3.3 环境（式舆防卫战 + 危局强袭战），仅代表一种主流评价，不等同于唯一答案。
- **译名口径**：优先中文官方译名；英文名用于跨语言检索，列在代理人表与术语表中。
- **不确定内容**：3.x 剧情细节、未实装角色、活动排期等，均标注「待官方确认」，不做臆测。

## 5. 维护

每次新版本上线，按 `AGENT.md` 的「进化层」更新：
1. 追加 `data/versions.csv` 一行；
2. 更新 `05-版本编年史.md`；
3. 新代理人写入 `06-代理人图鉴.md` 与 `data/agents.csv`；
4. 改动系统机制时同步 `02/03/04`；
5. 在 `CHANGELOG.md` 记录。
